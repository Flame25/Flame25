# Hi there, I'm Christopher 👋

Software engineer focused on systems programming, embedded firmware, and low-level optimization. I love squeezing every ounce of performance out of hardware—crafting lightweight, low-latency code for microcontrollers, autonomous UAVs, and high-performance backends.

---

### 🚀 Focus & Expertise
- **Low-Level & Firmware:** Embedded C, modern C++, custom hardware drivers, sensor integration, and real-time processing
- **Systems & Backend:** Performance profiling, memory optimization, and building scalable, concurrent services using **Go**
- **Robotics & Autonomy:** ROS / ROS 2, ArduPilot, Gazebo
- **Perception & Edge AI:** OpenCV, vision-based target detection, and lightweight inference (YOLO, PyTorch, TensorFlow)
